# Contributing to Awesome China Visa-Free Entry

Thanks for helping travelers enter China smoothly! Please keep it useful and clean.

## Criteria

1. Genuinely useful for visa-free entry or the first days in China
2. Currently working (no dead links, page updated recently)
3. Not already listed
4. Official or first-hand sources are preferred over aggregators

## Format

```markdown
- [Resource Name](URL) - Brief description explaining why it's useful
```

## How to submit

1. Fork this repo and create a branch
2. Add your entry to the most relevant section
3. Open a pull request with a short description of the resource

We review PRs within a week. Commercial submissions are fine if the resource is free and genuinely the best option — disclose your affiliation in the PR.
